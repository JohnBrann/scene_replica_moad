# Scene Replica MOAD

## Implementation of [SceneReplica](https://github.com/IRVLUTD/SceneReplica) and SceneReplica-related functionality from [ManipulationNet](https://github.com/ManipulationNet/mnet_client) designed for use with MOAD.

## Installation
You can install the dependencies with:

```bash
pip install opencv-python pupil-apriltags pybullet
```

## Usage

```bash
python3 client.py
```
